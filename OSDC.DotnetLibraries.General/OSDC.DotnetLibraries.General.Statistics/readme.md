## Version 3.3.6
Depends on OSDC.DotnetLibraries.General.Math 1.4.2. This release updates the dependency
without changing the Statistics API. Publish with generate-pack-push-statistics.yml, version 3.3.6.

Publication uses NuGet Trusted Publishing: configure the policy for GitHub owner
Open-Source-Drilling-Community, repository DotNetLibraries, workflow
generate-pack-push-statistics.yml, with no GitHub environment. The workflow uses
the repository NUGET_USER variable or secret and exchanges GitHub OIDC for a short-lived key.
